Frequently Asked Questions

Got questions about Sales Tracker Pro? We have answers.

How does Amazon S3 storage work in this project?
Uploaded product images and receipt PDFs route in memory buffers through the Express server directly into Amazon S3 bucket csbc252-sales-tracker-assets, ensuring zero local EC2 disk storage.
Can I test the app locally without connecting to Amazon RDS?
Yes! If DATABASE_URL is omitted, the backend server automatically falls back to an in-memory cloud datastore pre-loaded with mock sales and inventory items for instant testing.
Can I export transaction data for bookkeeping?
Absolutely. The Financial Reports section includes a one-click CSV export button that generates complete financial logs formatted for Excel or accounting software.
